Домашнее задание:

Создать в NestJS endpoint `POST /cars`, который принимает данные автомобиля через `@Body()` и валидирует их с помощью Zod.

Требования:

1. Создать Zod-схему `CreateCarSchema` со следующими полями:
   - `brand` — строка, минимум 2 символа
   - `model` — строка, минимум 1 символ
   - `year` — положительное целое число, не меньше 2000
   - `price` — положительное число

2. Использовать pipe в контроллере для обработки `POST /cars`

3. При успешной валидации endpoint должен возвращать полученные данные автомобиля
