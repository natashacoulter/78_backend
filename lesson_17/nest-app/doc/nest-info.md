# Nest.js
Nest.js - фраймворк для создания масштабируемых серверных приложений. Он написан на TypeScript и
предлагает строгую и предсказуемую структуру

Nest.js использует Express внутри себя по умолчанию в качестве базового HTTP сервера, а Nest выступает
в качестве  мощной архитектурной надстройки

Основные элементы:
1. Модули (@Module) - главные "кирпичики" приложения. Позволяют изолировать логику и инкапсулировать
внутри себя контроллеры и тпровайдеры
2. Контроллеры (@Controller) - отвечают за обработку запросов и возвращение ответов клиенту 
   (@Get("/users"), @Post())
3. Провайдеры/Сервисы(@Injectable) - содержат чистую бизнес-логику и внедряются в контроллеры

## NestJS и Express
Express:
 - чистый JS(можем подключать TS)
 - каждый разработчик строит структуру сам
 - масштабируемостть более сложная и есть риск превращения кода в "спагетти"
 - нужно подключать много дополнительных инстурментов, например для валидации

 NestJS:
 - сразу на TS
 - модульная архитектура
 - высокая масштабируемость
 - большое количество встроенных инструментов 

 ## Декораторы (@Module, @Controller, @Injectable, @Get)
 Декораторы - позволяют фраеймворку автоматически настраивать маршруты, валидацию, зависимости

 ## Настройку проекта
 Глобальная установка nest client
 ```
 npm i -g @nestjs/cli
 ```

 Установка проекта 
 ```
 nest new <название-проекта>
 ```

 Запуск приложения
 ```
 npm start
 ```

 Генерация модуля
 ```
 nest generate module <название модуля>
 ```

Генерация контроллера
 ```
 nest generate controller <название модуля>
 ```

Генерация сервиса
 ```
 nest generate service <название модуля>
 ```
